# Portfolio Clone

A responsive personal portfolio landing page inspired by a creative designer brand. The project uses static HTML, Tailwind CSS (via CDN), and a small JavaScript layer for theme switching and mobile navigation.

## Features
- Responsive layout for desktop and mobile screens
- Dark/light mode toggle with saved preference using `localStorage`
- Slide-out mobile menu with toggle animation
- Hero section with branding, profile image, and call-to-action button
- Clean portfolio-style design with modern gradients and typography

## Tech Stack
- HTML5
- Tailwind CSS
- Vanilla JavaScript

## Project Structure
- `tailwind-project.html` — main portfolio page markup and styling
- `script.js` — theme toggle, mobile menu logic, and UI interaction behavior
- `*.png` assets — branding, background, and profile images used by the design

## Running the Project
Use the **Live Server** extension in Visual Studio Code:
1. Install the Live Server extension if it is not already installed.
2. Open `tailwind-project.html` in VS Code.
3. Right-click inside the file and select **Open with Live Server**.

The page will open in your default browser. Live Server reloads the page when you save changes.

## Notes
- Tailwind styles are loaded from the CDN, so an internet connection is required to load the CSS framework.
- The site is designed as a static mock portfolio and is easy to customize by editing the HTML and assets.
